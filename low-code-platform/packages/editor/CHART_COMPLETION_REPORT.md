## 🎯 快速测试

### 访问地址
```
http://localhost:5175/editor?id=1
```

### 测试步骤

#### 1. 拖入图表组件
- 从左侧组件面板找到 "📊 图表"
- 拖入画布

#### 2. 查看默认效果
- 默认显示柱状图
- 数据：6 个月的销售数据
- 标题：销售数据
- 高度：300px

#### 3. 切换图表类型
在右侧属性面板：
- 切换为 "折线图" → 看到平滑曲线
- 切换为 "饼图" → 看到圆形占比图
- 切换为 "散点图" → 看到点状分布
- 切换为 "面积图" → 看到填充区域

#### 4. 修改数据
在 "数据源" 文本框中输入自定义 JSON：
```json
[
  { "name": "产品A", "value": 350 },
  { "name": "产品B", "value": 280 },
  { "name": "产品C", "value": 200 }
]
```

#### 5. 测试国际化
- 点击右上角语言切换
- 切换到英文
- 验证组件标签和属性翻译

## 🎨 示例数据模板

### 模板 1: 月度销售（默认）
```json
[
  { "name": "一月", "value": 120 },
  { "name": "二月", "value": 200 },
  { "name": "三月", "value": 150 },
  { "name": "四月", "value": 180 },
  { "name": "五月", "value": 220 },
  { "name": "六月", "value": 250 }
]
```

### 模板 2: 产品占比
```json
[
  { "category": "手机", "sales": 4500 },
  { "category": "电脑", "sales": 3200 },
  { "category": "平板", "sales": 2100 },
  { "category": "耳机", "sales": 1800 }
]
```
**图表类型**: 饼图  
**X轴字段**: category  
**Y轴字段**: sales

### 模板 3: 温度趋势
```json
[
  { "date": "周一", "temp": 18 },
  { "date": "周二", "temp": 22 },
  { "date": "周三", "temp": 25 },
  { "date": "周四", "temp": 20 },
  { "date": "周五", "temp": 23 }
]
```
**图表类型**: 折线图或面积图  
**X轴字段**: date  
**Y轴字段**: temp

## 💡 使用建议

### 选择合适的图表

**折线图/面积图**:
- ✅ 时间序列数据
- ✅ 趋势分析
- ❌ 少量数据点

**柱状图**:
- ✅ 类别对比
- ✅ 排名展示
- ❌ 太多类别（>20）

**饼图**:
- ✅ 占比关系
- ✅ 总量分配
- ❌ 类别太多（>7）
- ❌ 数值接近

**散点图**:
- ✅ 数据分布
- ✅ 相关性分析
- ❌ 少量数据

### 数据准备

1. **格式化**: 使用在线 JSON 格式化工具
2. **验证**: 确保字段名一致
3. **清洗**: 移除无效数据
4. **测试**: 先用少量数据测试
