## 🎨 组件详细说明

### 1. Card（卡片）组件

**用途**: 作为内容容器，用于组织和展示信息

**属性配置**:
- **标题** (title) - 卡片标题文本
- **内容** (content) - 卡片正文内容
- **边框** (bordered) - 是否显示边框
  - 无边框：使用阴影效果
  - 有边框：显示边框 + 轻阴影

**默认样式**:
- 白色背景
- 圆角 (rounded-lg)
- 内边距 16px
- 标题使用较大字体 (text-lg)
- 内容使用灰色字体

**使用场景**:
- 产品展示卡片
- 用户信息卡
- 统计数据展示
- 功能模块分组

**示例**:
```
┌─────────────────────────┐
│  卡片标题                │
│  ────────────────────    │
│  这是卡片内容，可以      │
│  显示详细的信息。        │
└─────────────────────────┘
```

---

### 2. Divider（分割线）组件

**用途**: 分隔不同内容区域，提升页面层次感

**属性配置**:
- **类型** (type) - 线条样式
  - solid (实线) - 默认
  - dashed (虚线)
  - dotted (点线)
- **方向** (orientation) - 分割线方向
  - horizontal (水平) - 默认
  - vertical (垂直)

**默认样式**:
- 灰色线条 (border-gray-300)
- 水平方向有上下间距 (my-4)
- 垂直方向有左右间距 (mx-4)

**使用场景**:
- 章节分隔
- 列表项分隔
- 侧边栏分隔
- 表单字段分组

**示例**:
```
内容区域 A
─────────────  (水平实线)
内容区域 B

侧边栏 │ 主内容  (垂直实线)
```

---

### 3. Badge（徽章）组件

**用途**: 显示状态、标签或数量提示

**属性配置**:
- **文本** (text) - 徽章显示的文字
- **颜色** (color) - 徽章颜色主题
  - primary (蓝色) - 主要信息
  - success (绿色) - 成功/完成
  - warning (黄色) - 警告
  - error (红色) - 错误/紧急
  - info (灰色) - 一般信息

**默认样式**:
- 圆角胶囊形状 (rounded-full)
- 小号字体 (text-xs)
- 紧凑内边距
- 颜色主题对应的浅色背景 + 深色文字

**使用场景**:
- 状态标签 (进行中/已完成/已关闭)
- 新功能标记 (New)
- 数量提示 (消息数、通知数)
- 分类标签

**示例**:
```
标题 [New]  文章标题 [热门]  状态: [进行中]
```

---

### 4. Alert（提示）组件

**用途**: 显示重要的提示、警告或错误信息

**属性配置**:
- **类型** (type) - 提示类型
  - info (信息) - 蓝色主题
  - success (成功) - 绿色主题
  - warning (警告) - 黄色主题
  - error (错误) - 红色主题
- **标题** (title) - 提示标题
- **消息** (message) - 详细消息内容
- **显示图标** (showIcon) - 是否显示图标
  - 显示：在左侧显示对应类型的图标
  - 隐藏：不显示图标

**图标映射**:
- info: ℹ️
- success: ✓
- warning: ⚠
- error: ✕

**默认样式**:
- 圆角容器 (rounded-lg)
- 边框 + 浅色背景
- 内边距 16px
- 图标在左侧，文字在右侧

**使用场景**:
- 操作反馈提示
- 表单验证错误
- 系统公告
- 警告信息
- 帮助提示

**示例**:
```
┌──────────────────────────────┐
│ ℹ️  提示信息                  │
│    这是一条重要的提示消息      │
└──────────────────────────────┘

┌──────────────────────────────┐
│ ⚠  警告                       │
│    请注意，这个操作不可撤销    │
└──────────────────────────────┘
```

## 🎨 设计规范

### 颜色系统

| 类型 | 背景色 | 文字色 | 边框色 |
|------|--------|--------|--------|
| Primary | blue-100 | blue-800 | blue-200 |
| Success | green-100 | green-800 | green-200 |
| Warning | yellow-100 | yellow-800 | yellow-200 |
| Error | red-100 | red-800 | red-200 |
| Info | gray-100 | gray-800 | gray-200 |

### 间距规范

- 组件内边距: 16px (p-4)
- 组件外边距: 16px (my-4 / mx-4)
- 元素间距: 8px (gap-2)

### 圆角规范

- 卡片: rounded-lg (8px)
- 徽章: rounded-full (完全圆角)
- 提示: rounded-lg (8px)
