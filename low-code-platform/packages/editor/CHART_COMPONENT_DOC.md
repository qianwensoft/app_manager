## 📊 组件概述

为 Low-Code 编辑器添加了功能强大的图表组件，基于 ECharts 实现，支持 5 种常用图表类型。

---

## 🎨 支持的图表类型

| 类型 | 中文名 | 英文名 | 适用场景 |
|------|--------|--------|---------|
| line | 折线图 | Line Chart | 展示趋势变化、时间序列数据 |
| bar | 柱状图 | Bar Chart | 比较不同类别的数据 |
| pie | 饼图 | Pie Chart | 展示占比关系 |
| scatter | 散点图 | Scatter Chart | 展示数据分布、相关性 |
| area | 面积图 | Area Chart | 展示趋势和累积 |

---

## 📝 属性配置

### 1. 图表类型 (chartType)
**类型**: 下拉选择  
**选项**:
- 折线图 (line)
- 柱状图 (bar)
- 饼图 (pie)
- 散点图 (scatter)
- 面积图 (area)

**默认值**: bar（柱状图）

### 2. 标题 (title)
**类型**: 文本输入  
**说明**: 图表顶部显示的标题  
**默认值**: "销售数据"

### 3. 高度 (height)
**类型**: 下拉选择  
**选项**:
- 小 (200px)
- 中 (300px)
- 大 (400px)
- 超大 (500px)

**默认值**: 300px

### 4. 数据源 (data)
**类型**: 文本域（JSON 格式）  
**格式**: JSON 数组  
**示例**:
```json
[
  { "name": "一月", "value": 120 },
  { "name": "二月", "value": 200 },
  { "name": "三月", "value": 150 }
]
```

**默认值**: 6 个月的示例数据

### 5. X轴字段 (xField)
**类型**: 文本输入  
**说明**: 指定数据中用作 X 轴的字段名  
**默认值**: "name"

### 6. Y轴字段 (yField)
**类型**: 文本输入  
**说明**: 指定数据中用作 Y 轴（数值）的字段名  
**默认值**: "value"

## 🛠️ 技术实现

### 依赖库
- **ECharts**: v6.1.0 - 强大的图表库
- **echarts-for-react**: v3.0.6 - React 封装

### 核心特性
1. **数据解析**: 自动解析 JSON 字符串或数组
2. **类型安全**: TypeScript 类型定义
3. **响应式**: SVG 渲染，自适应容器宽度
4. **交互性**: 内置 tooltip、hover 效果
5. **主题**: 使用 ECharts 默认配色

### 渲染器
使用 SVG 渲染器，优点：
- 高清晰度
- 支持导出
- 更好的缩放效果

## 📊 数据格式要求

### 通用格式
```json
[
  { "field1": "value1", "field2": 100 },
  { "field1": "value2", "field2": 200 }
]
```

### 必需字段
- **X轴字段**: 类别名称或数值
- **Y轴字段**: 数值（数字）

### 数据类型
- **折线图/柱状图/面积图**: X 为字符串，Y 为数字
- **饼图**: X 为分类，Y 为数值
- **散点图**: X 和 Y 都为数字

## 🔧 故障排除

### 问题 1: 图表不显示
**原因**: 数据格式错误  
**解决**: 检查 JSON 格式是否正确，是否包含必需字段

### 问题 2: 字段名不匹配
**原因**: xField/yField 与数据不对应  
**解决**: 确认字段名与 JSON 数据中的键名一致

### 问题 3: 图表变形
**原因**: 容器宽度限制  
**解决**: 确保父容器有足够宽度
