## 🔍 失败分析

### 核心问题

**WebSocket 连接环境差异**:

```typescript
// useYjsCollab.ts:36
const wsHost = process.env.NODE_ENV === 'development' ? 'localhost:8080' : window.location.host;
const wsUrl = `${wsProtocol}//${wsHost}/ws/yjs`;
```

- **开发模式**: 前端 (5174) → 后端 (8080) WebSocket
- **测试环境**: Playwright 可能无法正确代理跨端口 WebSocket 连接
- **结果**: Yjs WebSocket 未建立，只有 Vite HMR WebSocket

### 影响范围

失败的 3 个测试都依赖于：
1. Yjs WebSocket 成功连接到后端
2. Awareness 协议正常工作
3. 在线状态指示器正确显示
