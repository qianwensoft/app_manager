## 功能详情

### 1. 工作流设计器 ✅

**文件**: `web/src/views/data/WorkflowDesigner.vue`  
**路由**: `/workflow-designer`  
**菜单**: 工作流设计器

#### 核心功能

**三栏布局**：
- **左侧步骤面板** - 6种步骤类型，支持拖拽
- **中间画布区域** - 显示工作流结构
- **右侧属性编辑器** - 编辑选中步骤

**支持的步骤类型**：
| 图标 | 类型 | 名称 | 配置项 |
|------|------|------|--------|
| 🗄️ | `sql` | SQL 查询 | 数据源、SQL、事务组 |
| 🔗 | `http` | HTTP 请求 | 方法、URL、请求体、超时 |
| 📜 | `script` | 脚本执行 | 引擎、JavaScript代码 |
| 🔌 | `interface` | 接口调用 | 接口编码、参数 |
| ⏱️ | `delay` | 延迟 | 时长、单位 |
| ❓ | `condition` | 条件分支 | 表达式、分支 |

**高级配置**：
- ⚡ **异步执行** - 开关控制
- 🔄 **重试机制**：
  - 最大重试次数（1-10）
  - 退避策略（固定/线性/指数/自定义）
  - 重试间隔配置
  - 重试条件选择
- 📤 **输出配置** - JSON格式

**工具栏功能**：
- 📄 查看JSON - 导出/导入完整配置
- ✅ 验证工作流 - 检查配置完整性
- 🧪 测试运行 - 模拟执行（开发中）
- 💾 保存 - 保存到数据接口（开发中）

#### 使用流程

```
拖拽步骤 → 配置属性 → 设置高级选项 → 查看JSON → 复制到数据接口
```

### 2. 工作流执行日志 ✅

**文件**: `web/src/views/data/WorkflowExecutionLogs.vue`  
**路由**: `/workflow-logs`  
**菜单**: 工作流执行日志

#### 核心功能

**统计面板**（4个卡片）：
- 📊 总执行次数
- ✅ 成功率（百分比，带颜色）
- ⏱️ 平均时长（毫秒）
- ⚠️ 补偿次数

**执行日志列表**：
- 请求ID、接口编码
- 状态标签（成功🟢/失败🔴/已补偿🟡）
- 步骤进度条（完成数/总数）
- 耗时、补偿标识
- 创建时间

**筛选功能**：
- 按接口编码过滤
- 按状态过滤（成功/失败/补偿）
- 重新加载统计

**详情对话框**：
- 📋 基本信息描述列表
- 📊 步骤日志表格
  - 步骤ID、类型、状态
  - 耗时、重试次数
  - 错误信息
  - 输出数据（可折叠）

**时间线视图**：
- ⏰ 时间轴布局
- 📇 卡片式展示每个步骤
- 包含详细执行信息
- SQL语句显示
- 错误高亮

**操作功能**：
- 查看详情
- 查看时间线
- 重试执行（失败/补偿）

**分页**：
- 默认20条/页
- 支持20/50/100

### 3. 异步任务监控 ✅

**文件**: `web/src/views/data/AsyncTasksMonitor.vue`  
**路由**: `/async-tasks`  
**菜单**: 异步任务监控

#### 核心功能

**运行中任务标签页**：
- 📋 任务列表
  - 请求ID、步骤ID
  - 状态标签（等待/运行中/完成/失败）
  - 进度条显示
  - 开始时间
  - 已运行时长（实时计算）
- 🔄 自动刷新开关（每5秒）
- 🔍 查看详情和结果

**执行器统计标签页**：
- 📊 4个统计卡片：
  - 🔗 最大并发数
  - ⏳ 运行中任务
  - ✅ 已完成任务
  - 👤 可用工作线程
- 📈 使用率进度条
  - 绿色 < 70%
  - 黄色 70%-90%
  - 红色 > 90%
- 🗑️ 清理已完成任务
  - 可配置时间（分钟）
  - 默认60分钟

**任务详情对话框**：
- 基本信息
- 错误信息（如果失败）
- 执行结果
  - 成功状态
  - 耗时
  - 输出数据（可折叠）

#### 特色功能

- ⚡ 实时监控 - 自动刷新
- 🎨 状态可视化 - 颜色标识
- 📊 资源使用监控 - 避免过载

### 4. 死信队列管理 ✅

**文件**: `web/src/views/data/DeadLetterQueue.vue`  
**路由**: `/deadletter-queue`  
**菜单**: 死信队列管理

#### 核心功能

**统计面板**（4个卡片）：
- 📊 总数
- ⚠️ 待处理（黄色）
- 🔄 重试中（蓝色）
- ✅ 已处理（绿色）

**死信列表**：
- 请求ID、接口编码
- 状态标签（待处理/重试中/已处理/失败）
- 数据源
- 重试次数
- 创建时间
- 下次重试时间

**筛选功能**：
- 按状态过滤
- 按接口编码过滤
- 批量选择

**详情对话框**：
- 📋 基本信息
- 💾 补偿SQL（代码块显示）
- ❌ 最后错误信息
- 📝 处理备注

**操作功能**：
- 🔄 重试补偿
- ✅ 标记已处理（带备注）
- 🗑️ 删除死信
- 📦 批量删除
- 🧹 清理已处理记录（按天数）

**标记已处理**：
- 弹窗输入处理备注
- 记录处理时间
- 说明手动处理的原因

**清理功能**：
- 配置保留天数（1-365天）
- 默认30天
- 仅清理已处理的记录
- 二次确认

#### 使用场景

1. **日常监控**：查看待处理和重试中的死信
2. **问题处理**：查看详情、手动处理、标记已处理
3. **批量操作**：选中多条记录批量删除
4. **定期清理**：清理历史已处理记录

## API 集成

所有界面都通过 Axios 调用后端 API：

```javascript
// 工作流执行日志
GET  /api/data-stack/workflow-executions
GET  /api/data-stack/workflow-executions/stats
POST /api/data-stack/workflow-executions/:request_id/retry

// 异步任务
GET  /api/data-stack/async-tasks
GET  /api/data-stack/async-tasks/stats
POST /api/data-stack/async-tasks/cleanup

// 死信队列
GET  /api/data-stack/compensation-deadletters
GET  /api/data-stack/compensation-deadletters/stats
POST /api/data-stack/compensation-deadletters/:id/retry
POST /api/data-stack/compensation-deadletters/:id/mark-processed
DELETE /api/data-stack/compensation-deadletters/:id
POST /api/data-stack/compensation-deadletters/batch-delete
POST /api/data-stack/compensation-deadletters/purge-processed
```

## 问题排查

### Q1: 页面空白或加载失败
**检查**：
1. 后端服务是否启动（:8080）
2. 浏览器控制台是否有错误
3. API 请求是否正常（Network 标签）

### Q2: 数据不显示
**检查**：
1. 是否有执行记录/异步任务/死信
2. 筛选条件是否正确
3. 后端数据是否正常返回

### Q3: 拖拽不工作
**检查**：
1. 浏览器是否支持 Drag API
2. 是否正确触发 dragstart 事件
3. 控制台是否有 JavaScript 错误
