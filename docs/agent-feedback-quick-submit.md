# Agent 问题反馈 - 扫码快速提交功能

**完成日期**: 2026-06-30  
**功能**: 增加"扫码后立即提交"复选框，扫码业务单号后自动提交工单

---

## 🎯 功能概述

在 Agent 问题反馈页面新增**扫码快速提交**模式，适用于现场快速报障场景：

1. 提前填好标题和问题描述
2. 勾选"扫码后立即提交"复选框
3. 扫描业务单号（设备码/资产码等）
4. 自动弹出确认对话框并提交工单

---

## 📱 使用场景

### 场景 1：现场巡检报障

**传统流程**（5 步）：
```
1. 打开反馈页面
2. 填写标题、描述
3. 扫码业务单号
4. 点击"提交反馈"按钮
5. 确认提交
```

**快速提交流程**（3 步）：
```
1. 打开反馈页面，填写标题"设备故障"，描述"无法启动"
2. 勾选"扫码后立即提交"
3. 扫设备码 → 自动提交
```

### 场景 2：批量报障

维修人员巡检多台设备，遇到相同问题：

```
1. 填写标题"电源故障"，描述"指示灯不亮"
2. 勾选"扫码后立即提交"
3. 依次扫描故障设备码：
   - 扫设备 A → 确认 → 提交 ✓
   - 扫设备 B → 确认 → 提交 ✓
   - 扫设备 C → 确认 → 提交 ✓
```

**效率提升**：从每台 5 步变成每台 1 步（扫码）


```
─────────────────────────────────────────────

勾选"扫码后立即提交"        →    启用快速提交模式

扫描业务单号                →    ① 填入业务单号
```

## 💡 技术实现

### 1. 布局修改（activity_feedback.xml）

```xml
<!-- 业务单号输入框 -->
<TextInputLayout android:id="@+id/tilBusinessNo">
    <TextInputEditText android:id="@+id/etBusinessNo" />
</TextInputLayout>

<!-- 新增：扫码即提交复选框 -->
<CheckBox
    android:id="@+id/cbQuickSubmit"
    android:text="扫码后立即提交（保留标题和问题描述）" />
```

### 2. FeedbackActivity 逻辑

```kotlin
// 新增字段
private lateinit var cbQuickSubmit: CheckBox

override fun onCreate(savedInstanceState: Bundle?) {
    // ...
    cbQuickSubmit = findViewById(R.id.cbQuickSubmit)
}

private fun handleScanResult(code: String) {
    when (scanTarget) {
        "business_no" -> {
            etBusinessNo.setText(code)
            Toast.makeText("已填入业务单号")
            
            // 新增：检查是否启用快速提交
            if (cbQuickSubmit.isChecked) {
                quickSubmitWithBusinessNo()
            }
        }
    }
}

private fun quickSubmitWithBusinessNo() {
    val title = etTitle.text?.toString()?.trim() ?: ""
    val desc = etDesc.text?.toString()?.trim() ?: ""
    
    if (title.isEmpty()) {
        Toast.makeText("请先填写标题")
        return
    }
    
    // 弹出确认对话框
    AlertDialog.Builder(this)
        .setTitle("确认提交")
        .setMessage("""
            业务单号: ${etBusinessNo.text}
            标题: $title
            描述: ${if (desc.isEmpty()) "（无）" else desc}
            
            确定立即提交反馈？
        """)
        .setPositiveButton("提交") { _, _ ->
            submit()  // 调用原有的提交方法
        }
        .setNegativeButton("取消", null)
        .show()
}
```

## 📋 使用说明

### 标准使用流程

1. **打开反馈页面**
   - 从 Agent 主界面点击"问题反馈"

2. **填写基本信息**
   ```
   工单类型：选择"设备故障"
   标题：设备无法启动（必填）
   描述：电源指示灯不亮，按开机键无反应（选填）
   ```

3. **启用快速提交**
   - 勾选"扫码后立即提交"复选框

4. **扫描业务单号**
   - 点击业务单号输入框右侧的📷图标
   - 或直接使用硬件扫码枪扫描
   - 扫到业务单号后自动填入并弹出确认对话框

5. **确认并提交**
   - 检查确认对话框中的信息
   - 点击"提交"完成提交
   - 或点击"取消"修改后重新扫码

### 批量提交技巧

**场景**：巡检发现 10 台设备相同故障

```
1. 填写一次标题和描述：
   标题: "电源故障"
   描述: "指示灯不亮"

2. 勾选"扫码后立即提交"

3. 连续扫描 10 台设备：
   扫设备1 → 确认 → 提交 → 完成
   扫设备2 → 确认 → 提交 → 完成
   ...
   扫设备10 → 确认 → 提交 → 完成
```

**时间对比**：
- 传统方式：10 台 × 5 步 = 50 个操作
- 快速提交：1 次填写 + 10 次扫码确认 = 11 个操作
- **效率提升 78%**

## ⚠️ 注意事项

### 1. 标题必填

扫码后如果标题为空，会提示：

```
请先填写标题
```

不会弹出确认对话框，需要填写标题后重新扫码。

### 2. 描述可选

描述字段可以为空，确认对话框会显示"（无）"。

### 3. 复选框状态保留

复选框的勾选状态在页面内保留，切换标签页或退出页面后重置。

### 4. 取消后可重新扫码

点击确认对话框的"取消"按钮后：
- 业务单号保留在输入框
- 可以修改标题、描述或其他内容
- 重新扫码或手动点击"提交反馈"按钮

### 5. 与手动提交等效

快速提交调用的是原有的 `submit()` 方法，功能完全一致：
- 验证必填项
- 上传附件
- 发送到服务器
- 显示提交结果
