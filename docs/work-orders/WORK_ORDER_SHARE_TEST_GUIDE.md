# 工单分享权限功能测试指南

## ⚠️ 重要：清除浏览器缓存

修改已部署，但需要清除浏览器缓存才能看到新版本：

### 方法 1：硬刷新（推荐）
- **Chrome/Edge**: `Cmd+Shift+R` (Mac) 或 `Ctrl+Shift+R` (Windows)
- **Safari**: `Cmd+Option+R`
- **Firefox**: `Cmd+Shift+R` (Mac) 或 `Ctrl+Shift+R` (Windows)

### 方法 2：清除缓存
1. 打开浏览器开发者工具（F12）
2. 右键点击刷新按钮
3. 选择"清空缓存并硬性重新加载"

### 方法 3：无痕模式
使用无痕/隐私浏览模式打开分享链接

## 测试步骤

### 1. 创建需登录分享链接

访问工单管理页面：
1. 点击"统计分析"按钮
2. 点击"生成分享链接"
3. 填写分享标题：`测试需登录权限`
4. 选择有效期：`7天`
5. **认证模式选择："需登录"** ⚠️ 重要
6. 勾选权限：
   - ✅ 查看工单详情（默认勾选，不可取消）
   - ✅ 添加评论
   - ✅ 更新工单状态
   - ✅ 更新工单字段
7. 点击"生成链接"
8. 复制分享链接

### 2. 访问分享链接（未登录状态）

1. 打开无痕窗口
2. 粘贴分享链接并访问
3. **预期结果**：
   - ✅ 可以看到工单列表和统计
   - ✅ 点击工单可以查看详情
   - ✅ 看到提示："请登录后查看更多操作权限"
   - ✅ footer 只有"关闭"按钮，没有操作按钮

### 3. 登录并查看权限

1. 使用第三方账号登录（或系统账号）
2. 登录成功后自动返回分享页面
3. 点击任意工单查看详情
4. **预期结果**：
   - ✅ **不再显示"此为只读分享页面"提示**
   - ✅ footer 左侧显示三个操作按钮：
     - 🔵 "添加评论"按钮（主要按钮，蓝色）
     - ⚪ "更新状态"按钮
     - ⚪ "编辑工单"按钮
   - ✅ footer 右侧显示"关闭"按钮

### 4. 测试添加评论

1. 点击"添加评论"按钮
2. **预期结果**：弹出"添加评论"对话框
3. 输入评论内容：`测试通过分享链接添加评论`
4. 点击"提交"
5. **预期结果**：
   - ✅ 显示"评论添加成功"提示
   - ✅ 对话框关闭
   - ✅ 工单进展列表自动刷新
   - ✅ 新评论出现在进展列表中

### 5. 测试更新状态

1. 点击"更新状态"按钮
2. **预期结果**：弹出"更新工单状态"对话框
3. 可以看到：
   - 当前状态（例如："待处理"）
   - 新状态下拉框
   - 备注输入框
4. 选择新状态：`处理中`
5. 输入备注：`开始处理此工单`
6. 点击"提交"
7. **预期结果**：
   - ✅ 显示"状态更新成功"提示
   - ✅ 对话框关闭
   - ✅ 工单详情中的状态标签变为"处理中"
   - ✅ 工单列表刷新，该工单移到"处理中"列

### 6. 测试编辑工单

1. 点击"编辑工单"按钮
2. **预期结果**：弹出"编辑工单"对话框
3. 可以看到：
   - 标题输入框（已填充当前标题）
   - 描述输入框（已填充当前描述）
   - 优先级下拉框（已选中当前优先级）
4. 修改标题：在原标题后加 ` - 已编辑`
5. 修改优先级：改为`高`
6. 点击"提交"
7. **预期结果**：
   - ✅ 显示"工单更新成功"提示
   - ✅ 对话框关闭
   - ✅ 工单详情中的标题和优先级更新
   - ✅ 工单列表刷新，显示新的标题和优先级

### 7. 测试部分权限

创建一个只有评论权限的分享链接：

1. 重新创建分享链接
2. 认证模式选择："需登录"
3. **只勾选**：✅ 添加评论
4. 取消勾选：❌ 更新工单状态、❌ 更新工单字段
5. 生成链接并访问
6. 登录后查看工单详情
7. **预期结果**：
   - ✅ 只显示"添加评论"按钮
   - ❌ 不显示"更新状态"按钮
   - ❌ 不显示"编辑工单"按钮

### 8. 测试只读分享（对照组）

创建一个免登录分享链接：

1. 创建新分享链接
2. 认证模式选择："免登录"
3. 生成链接并访问
4. 查看工单详情
5. **预期结果**：
   - ✅ 显示"此为只读分享页面，不支持编辑操作"提示
   - ❌ 没有任何操作按钮
   - ✅ 只有"关闭"按钮

## 验证要点总结

| 场景 | 提示信息 | 操作按钮 |
|------|----------|----------|
| 免登录模式 | "此为只读分享页面，不支持编辑操作" | 无 |
| 需登录模式（未登录） | "请登录后查看更多操作权限" | 无 |
| 需登录模式（已登录，有权限） | 不显示提示 | 根据权限显示 1-3 个按钮 |
| 需登录模式（已登录，无权限） | "此分享链接为只读权限" | 无 |

## 常见问题排查

### Q: 还是显示"此为只读分享页面"
**A**: 清除浏览器缓存后重试（按 Cmd+Shift+R）

### Q: 看不到操作按钮
**A**: 检查：
1. 是否选择了"需登录"模式
2. 是否已经登录（查看浏览器开发者工具 → Application → Local Storage，确认有 token）
3. 创建分享时是否勾选了相应权限

### Q: 操作失败，提示权限不足
**A**: 可能原因：
1. Token 过期，需要重新登录
2. 分享链接过期，需要重新创建
3. 后端权限检查失败，查看浏览器控制台错误信息

### Q: 如何查看后端返回的权限配置
**A**: 
1. 打开浏览器开发者工具（F12）
2. 切换到 Network 标签
3. 刷新页面
4. 找到 `/api/share/work-order-reports/{token}` 请求
5. 查看 Response，确认 `auth_mode` 和 `permissions` 字段

## 开发者调试

### 查看分享信息

在浏览器控制台输入：
```javascript
// 查看分享信息
console.log('shareInfo:', shareInfo)

// 查看权限配置
console.log('permissions:', shareInfo?.permissions)

// 查看登录状态
console.log('is_authenticated:', shareInfo?.is_authenticated)
```

### 查看 localStorage 中的 token

```javascript
console.log('token:', localStorage.getItem('token'))
```

### 手动测试 API

```javascript
// 测试添加评论
fetch('/api/share/work-order-reports/{token}/work-orders/{id}/comment', {
  method: 'POST',
  headers: {
    'Content-Type': 'application/json',
    'Authorization': 'Bearer ' + localStorage.getItem('token')
  },
  body: JSON.stringify({ comment: '测试评论' })
}).then(r => r.json()).then(console.log)
```
