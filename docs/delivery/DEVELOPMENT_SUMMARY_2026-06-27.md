- **样式**: 白色背景 + 圆角 + 阴影/边框

- **用途**: 内容分隔
- **属性**: 类型（实线/虚线/点线）、方向（水平/垂直）
- **样式**: 灰色线条 + 可配置样式

- **属性**: 文本、颜色（5 种主题）
- **样式**: 圆角胶囊 + 主题配色

- **用途**: 消息提示、警告信息

- **样式**: 圆角容器 + 图标 + 主题配色

## 🎯 如何使用

### Yjs 协同编辑

```bash
# 1. 启动后端
cd server && go run . config.sqlite.yaml

# 2. 启动前端
cd low-code-platform/packages/editor && pnpm dev

# 3. 测试协同编辑
# 打开两个浏览器窗口
# 访问: http://localhost:5174/editor?id=1
# 登录: admin / admin123
# 观察右上角在线人数实时变化
```
