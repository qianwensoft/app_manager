# Android 工单模块 - 快速部署和测试指南

## 部署步骤

### 1. 构建 APK

```bash
# 在项目根目录执行
make agent

# 构建产物位置
# agent/app/build/outputs/apk/debug/app-debug.apk
```

### 2. 安装到设备

```bash
# 通过 ADB 安装
make install-agent

# 或手动安装
adb install -r agent/app/build/outputs/apk/debug/app-debug.apk
```

### 3. 服务器端配置

服务器端无需额外配置，但需要确认：

1. **菜单已下发**：
   - 登录管理后台
   - 进入设备管理
   - 为目标设备分配"工单处理"和"我的工单"菜单项
   
2. **设备已连接**：
   - 确认设备 Agent 已连接到服务器
   - 设备状态显示为在线

3. **工单数据准备**：
   - 创建几个测试工单用于验证
   - 确保有不同状态、优先级的工单

## 测试清单

### ✅ 任务 #1: 验证菜单启动功能

**操作步骤：**
1. 在设备上打开 Agent 应用
2. 点击后台菜单按钮
3. 查看是否显示"工单处理"和"我的工单"菜单项
4. 点击"我的工单"
5. 点击"工单处理"

**预期结果：**
- 两个菜单项都能正常打开对应页面
- 无崩溃或错误提示
- 页面标题正确显示

**排查问题：**
- 如果菜单不显示：检查服务器端是否已为该设备分配菜单
- 如果点击无反应：查看 logcat 日志 `adb logcat | grep BackendMenuActivity`

---

### ✅ 任务 #2: 验证下拉刷新功能

**操作步骤：**
1. 打开工单列表页面
2. 在列表顶部向下拉动手指
3. 观察刷新指示器
4. 等待数据加载完成

**预期结果：**
- 出现圆形刷新指示器

**排查问题：**
- 查看 logcat：`adb logcat | grep MyWorkOrderListActivity`
- 检查网络连接和服务器状态

### ✅ 任务 #3: 验证扫码搜索功能

**操作步骤：**
1. 打开工单列表页面
2. 点击右下角相机悬浮按钮
3. 首次使用需授予相机权限
4. 扫描二维码（可用任何包含文字的二维码测试）
5. 观察搜索结果
6. 点击工具栏的"清除搜索"按钮

**预期结果：**
- 相机正常启动
- 扫描成功后显示 Toast："搜索: {扫描值}"
- 工具栏副标题显示："搜索: {扫描值}"
- 列表过滤为匹配的工单
- 工具栏显示"X"清除按钮
- 点击清除后恢复完整列表，副标题和清除按钮消失

**测试用二维码内容示例：**
- 工单编号：`Y2606220001`
- 业务单号：`BIZ-2024-001`
- 任意包含关键词的文本

**排查问题：**
- 相机无法启动：检查权限是否授予
- 扫描后无反应：查看 logcat 过滤 `MyWorkOrderListActivity`
- 查找不到结果：确认服务器有匹配的工单数据

## 常见问题排查

### 问题：菜单中没有工单相关选项

**原因：**
- 服务器未将菜单分配给该设备
- 菜单同步失败

**解决：**
1. 检查服务器端菜单配置
2. 在设备上重启 Agent 服务
3. 查看 AgentMenuSync 日志

### 问题：点击菜单无反应或显示"打开失败"

**原因：**
- Activity 未正确注册到 AndroidManifest.xml
- Intent 启动失败

**解决：**
1. 检查 logcat 错误信息
2. 确认 APK 是最新构建版本
3. 重新安装 APK

### 问题：列表一直显示加载中

**原因：**
- 网络连接问题
- 服务器 API 响应超时
- 认证失败

**解决：**
1. 检查设备网络连接
2. 查看服务器日志
3. 确认 device-token 有效

### 问题：扫码后无法搜索

**原因：**
- 相机权限未授予
- 扫描库初始化失败
- 搜索参数未正确传递

**解决：**
1. 检查相机权限
2. 查看 logcat 扫描相关日志
3. 确认 ZXing 库正常加载

## 性能基准

**预期性能指标：**
- APK 大小：约 29 MB
- 列表加载时间：< 2 秒（50 条工单）
- 下拉刷新响应：< 100ms
- 扫码识别速度：< 500ms
- 页面切换动画：流畅 60fps

如果遇到问题，收集以下日志信息：

```bash

# 收集崩溃日志
adb logcat -d | grep -E "(AndroidRuntime|FATAL)" > crash_logs.txt

# 收集网络请求日志
adb logcat -d | grep -E "(OkHttp|AgentCatalogApi)" > network_logs.txt
```
