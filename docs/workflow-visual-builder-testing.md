# 工作流可视化编辑器 - 测试指南

## 测试准备

1. 启动服务器
```bash
cd server
go run . config.sqlite.yaml
```

2. 启动前端开发服务器（或使用构建后的版本）
```bash
cd web
npm run dev
# 或使用已构建的版本访问 http://localhost:8080
```

3. 登录系统，进入"工单设置" → "工单工作流"

## 测试场景

### 场景 1：上下文变量管理

**目的**：验证上下文变量的添加、显示和删除

**步骤**：
1. 点击"新建工作流"
2. 在"上下文变量（Context）"区域，点击"添加变量"
3. 输入：
   - 变量名：`user_id`
   - 描述：`当前用户ID`
   - 默认值：`123`
4. 点击"添加"
5. 验证变量出现在标签列表中
6. 点击标签的 X 删除变量
7. 验证变量被移除

**预期结果**：
- ✅ 变量成功添加并显示
- ✅ 变量可以正常删除
- ✅ 重复变量名提示错误

---

### 场景 2：执行 JavaScript - Monaco Editor

**目的**：验证 Monaco Editor 的初始化、代码编辑和智能提示

**步骤**：
1. 添加动作，选择"执行 JavaScript"
2. 点击"切换到可视化配置"
3. 等待 Monaco Editor 加载（约 1-2 秒）
4. 在编辑器中输入代码：
```javascript
log('工单编号:', workOrder.code);
log('工单标题:', workOrder.title);
if (workOrder.status === 'open') {
  log('工单状态为打开');
}
```
5. 测试智能提示：
   - 输入 `workOrder.` 后应该显示字段提示
   - 输入 `ctx.` 后应该显示上下文变量提示（如果定义了）
6. 展开"可用字段参考"折叠面板，查看字段说明
7. 查看"生成的配置"区域，验证 JSON 正确生成

**预期结果**：
- ✅ Monaco Editor 正确渲染，白色背景，可编辑
- ✅ 代码高亮正常（关键字、字符串等有不同颜色）
- ✅ 智能提示工作（输入 `workOrder.` 后显示字段列表）
- ✅ 实时生成 JSON：`{"code": "log('工单编号:', workOrder.code);..."}`
- ✅ 折叠面板可展开/收起

**常见问题排查**：
- 如果编辑器显示空白：等待 2-3 秒让编辑器初始化
- 如果无法编辑：刷新页面重新打开对话框
- 如果没有智能提示：检查浏览器控制台是否有错误

---

### 场景 3：调用第三方接口

**目的**：验证接口选择、参数映射和模板变量插入

**前提条件**：需要先在"对外集成" → "第三方接口"中创建至少一个接口

**步骤**：
1. 添加上下文变量：`api_token`
2. 添加动作，选择"调用第三方接口"
3. 点击"切换到可视化配置"
4. 在"选择第三方接口"下拉框中选择一个接口
5. 等待参数自动加载
6. 对于每个参数：
   - 手动输入固定值，或
   - 点击输入框右侧的下拉按钮
   - 选择模板变量（工单字段、上下文变量、前序动作结果）
7. （可选）在"结果保存到上下文"输入：`api_response`
8. 查看"生成的配置"

**预期结果**：
- ✅ 接口列表正确加载
- ✅ 选择接口后参数自动加载并显示
- ✅ 必填参数显示红色"必填"标签
- ✅ 参数类型正确显示
- ✅ 模板变量下拉菜单包含：
  - 工单字段（code、title 等）
  - 上下文变量（api_token）
  - 前序动作结果（如果是第 2+ 个动作）
- ✅ 插入的模板变量正确显示在输入框中
- ✅ JSON 配置正确生成：
```json
{
  "endpoint_id": 1,
  "params": {
    "token": "{{ctx.api_token}}",
    "work_order_code": "{{code}}"
  },
  "save_to_context": "api_response"
}
```

## 已知问题和限制

1. **Monaco Editor 初始化延迟**
   - 现象：切换到可视化模式后，编辑器可能需要 1-2 秒才能完全加载
   - 原因：Monaco Editor 是一个大型组件，需要时间初始化
   - 解决方案：已添加 setTimeout 延迟，通常可正常工作

2. **对话框关闭后编辑器未清理**
   - 现象：关闭对话框后重新打开，Monaco Editor 可能显示旧内容
   - 解决方案：已添加 `onBeforeUnmount` 钩子清理所有编辑器实例

3. **大量上下文变量时的类型提示**
   - 现象：超过 20 个上下文变量时，类型提示可能变慢
   - 建议：保持上下文变量数量在合理范围内（< 10 个）
