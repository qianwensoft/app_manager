# 工作流编辑卡死问题修复验证清单

## 问题描述
编辑工作流时系统卡死，页面无响应。

## 根本原因
实现标签页功能时，`<el-tabs>` 组件绑定到 `action.activeTab`，但加载现有工作流时没有初始化该属性，导致 Vue 响应式系统出现问题。

## 已修复内容
1. ✅ `openEdit` - 加载工作流时初始化 `activeTab`
2. ✅ `copyWorkflow` - 复制工作流时初始化 `activeTab`
3. ✅ `addAction` / `insertAction` - 新建动作时初始化 `activeTab`
4. ✅ `onActionTypeChange` - 改变动作类型时初始化 `activeTab`
5. ✅ 临时移除未完成的 Monaco JSON 编辑器（JSON 标签页使用普通 textarea）

## 手动验证步骤

### 1. 测试加载现有工作流
- [ ] 导航到 http://localhost:3001/work-orders/workflows
- [ ] 点击任意工作流的"编辑"按钮
- [ ] ✅ 对话框应该正常打开，页面不卡死
- [ ] ✅ 检查浏览器控制台，应该没有错误

### 2. 测试动作展开/收起
- [ ] 在编辑对话框中，点击动作标题栏
- [ ] ✅ 动作应该正常展开/收起
- [ ] ✅ 收起状态应该显示执行条件（如果有）

### 3. 测试标签页切换（call_endpoint 类型）
- [ ] 找到一个"调用第三方接口"类型的动作
- [ ] 点击"可视化配置"和"JSON 配置"标签
- [ ] ✅ 标签页应该正常切换
- [ ] ✅ JSON 配置显示为 textarea（可编辑）

### 4. 测试动作插入功能
- [ ] 点击动作标题栏的"向前添加"按钮
- [ ] ✅ 应该在当前动作前插入一个新动作
- [ ] 点击"向后添加"按钮
- [ ] ✅ 应该在当前动作后插入一个新动作

### 5. 测试新建动作
- [ ] 点击"添加动作"按钮
- [ ] 选择一个动作类型
- [ ] ✅ 动作配置应该正常显示
- [ ] ✅ 页面应该保持响应

### 6. 测试保存工作流
- [ ] 修改工作流名称或配置
- [ ] 点击"保存"按钮
- [ ] ✅ 应该成功保存并关闭对话框
- [ ] ✅ 列表应该显示更新后的工作流

### 7. 测试复制工作流
- [ ] 点击"复制"按钮
- [ ] ✅ 对话框应该打开，显示复制的工作流
- [ ] ✅ 页面不卡死

## 已知限制
- JSON 配置标签页暂时使用普通 textarea，尚未集成 Monaco 编辑器（待后续完善）
- 只有 `call_endpoint` 类型的动作实现了标签页，其他类型仍使用旧的切换按钮方式
